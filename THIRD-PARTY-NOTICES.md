# Third-party notices

Snippetpal self-contained Windows distributions include the Microsoft .NET 10 runtime and Windows Desktop (WPF / Windows Forms) runtime components. The application uses no third-party NuGet packages at runtime.

The .NET source projects are MIT licensed; the bundled runtime license and third-party notice files are copied from the actual runtime distribution into `notices/` in the portable and installed distributions.

- [.NET runtime license](https://github.com/dotnet/runtime/blob/main/LICENSE.TXT)
- [.NET runtime third-party notices](https://github.com/dotnet/runtime/blob/main/THIRD-PARTY-NOTICES.TXT)
- [WPF license](https://github.com/dotnet/wpf/blob/main/LICENSE.TXT)
- [Windows Forms license](https://github.com/dotnet/winforms/blob/main/LICENSE.TXT)

The setup executable is built with [NSIS 3.13](https://nsis.sourceforge.io/). Its [licenses](https://nsis.sourceforge.io/Docs/AppendixI.html) are included as `notices/NSIS-COPYING.txt` in installer builds. The compiler is downloaded from the official SourceForge project and is not installed with Snippetpal. NSIS source code is available from its official project.

The retained WiX MSI source is unused by current builds. WiX is not bundled with Snippetpal.

Windows UI fonts are used from the operating system and are not redistributed. The Snippetpal icon is generated by the included `scripts/create-icon.ps1` source.
